ASHLEY AFFECTION WEBSITE

How to use:
1. Open index.html in any browser to preview the website.
2. To publish it online, upload index.html to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
3. You can edit the text in index.html to make the message more personal.

The website is mobile-friendly and includes a letter, affection cards, floating hearts, and a surprise button.
